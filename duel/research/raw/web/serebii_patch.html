Release Dates:

May 31st 2016

Size:

  • ??

Alterations:

  • Added new "Gold Skills". Gold Skills beat Purple Skills and can stun the opponent
  • Added the new hotel, Iridium

  • Various Figure Alterations

Notes

Version 1.1
Release Dates:

June 14th 2016

Size:

  • 77.4MN

Alterations:

  • Added Queen's Cup event
  • Status Affliction Alterations
    • Paralysis: No longer choses the attack that is removed randomly, instead it goes for the smallest
  • Move Alterations
    • Psychic Blow: Fixed an issue where only the Pokémon that moved had to wait after being pushed back. Now all Pokémon have to wait
    • Focus Energy: Fixed an issue where if a non-White attack came up after selecting Focus Energy, the effect would have been that move rather than a 0 damage Focus Enegy move.
    • Swords Dance: Fixed an issue where if a non-White attack came up after selecting Swords Dance, the effect would have been that move rather than a 0 damage Swords Dance move.
    • Fake Tears: Fixed an issue where if a non-White attack came up after selecting Fake Tears, the effect would have been that move rather than a 0 damage Fake Tears move.
    • Throwback: Altered it so if a Pokémon is knocked backwards, they can also choose to go on a diagonal route if one exists.
  • Added new figures:

Notes
This update is required for your game to go online.
